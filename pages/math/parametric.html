dy/dx = (dy/dt) / (dx/dt) (단, dx/dt ≠ 0) 추천 탐구 미션 1. x(t) = cos(t), y(t) = sin(t)를 골라 원 위를 도는 점 P와 접선을 관찰해 보세요. 2. x(t)와 y(t)를 서로 바꿔보고, 곡선이 x = y 직선에 대해 어떻게 대칭되는지 확인해 보세요. 3. y(t) = ln(t)를 선택해 t가 0에 가까워질 때 dy/dt가 어떻게 커지는지 살펴보세요.

개념 설명

평면 위의 점 P(x, y)가 매개변수 t에 의해 x = x(t), y = y(t)로 각각 결정될 때, t가 변함에 따라 P는 곡선을 그립니다. 이때 곡선의 접선 기울기는 x, y를 각각 t로 미분한 dx/dt, dy/dt의 비율로 구할 수 있습니다(연쇄법칙). 아래 시각화에서 점 P 위의 두 화살표는 각각 dx/dt(가로 방향 순간 변화율), dy/dt(세로 방향 순간 변화율)를 나타내며, 두 화살표의 합성이 곡선의 접선 방향과 일치하는 것을 확인할 수 있습니다. dx/dt = 0이 되는 순간에는 접선이 수직이 되어 dy/dx가 정의되지 않습니다.

관련 수식

x = x(t), y = y(t) dy/dx = (dy/dt) / (dx/dt), 단 dx/dt ≠ 0 dx/dt = 0 인 지점 → 접선이 y축과 평행 (수직접선)
