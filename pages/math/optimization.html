최적화

넓이·부피 같은 값을 하나의 변수에 대한 함수로 나타낸 뒤, 도함수를 이용해 최댓값·최솟값을 찾는 세 가지 대표 상황을 시각화합니다. 슬라이더로 변수를 바꾸면 도형, 함수 그래프, 도함수 그래프가 함께 움직입니다.

시각화 영역 · #sim-stage

가로 x: 0 넓이 A(x): 0 A′(x): 0

넓이 함수 A(x)

도함수 A′(x)

Tip. 둘레 L이 고정된 직사각형에서 가로를 x라 하면 세로는 (L/2 − x)입니다. A′(x) = 0이 되는 지점(그래프의 점선)에서 넓이가 최대가 됩니다.

반지름 r: 0 표면적 S(r): 0 S′(r): 0

도함수 S′(r)

Tip. 부피 V가 고정된 원기둥에서 반지름을 r이라 하면 높이는 V/(πr²)입니다. 표면적 S(r) = 2πr² + 2V/r을 최소로 하는 r을 찾습니다.

부피 함수 V(x)

도함수 V′(x)

Tip. 한 변이 a인 정사각형 판지의 네 모서리에서 변의 길이 x인 정사각형을 잘라내고 접으면 부피 V(x) = x(a − 2x)²인 뚜껑 없는 상자가 됩니다.

개념 설명

세 상황 모두 "조건 하나가 고정된 상태에서, 나머지를 하나의 변수 x로 표현한 함수의 최댓값(또는 최솟값)을 찾는다"는 같은 구조를 갖습니다. 함수 f(x)를 세우고 나면, 도함수 f′(x) = 0이 되는 지점에서 극값(최댓값·최솟값 후보)이 나타납니다. 그래프에서 f(x) 곡선의 봉우리(또는 골짜기)와, f′(x) 곡선이 0을 지나는 지점(점선)이 같은 x값에서 만나는 것을 확인해 보세요. 슬라이더로 고정 조건(둘레, 부피, 판지 크기)을 바꾸면 최적의 x값 자체도 달라집니다.

관련 수식

① 울타리: A(x) = x(L/2 − x), A′(x) = L/2 − 2x

② 원기둥 캔: S(r) = 2πr² + 2V/r, S′(r) = 4πr − 2V/r²

③ 상자: V(x) = x(a − 2x)², V′(x) = 12x² − 8ax + a²
